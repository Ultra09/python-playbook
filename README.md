# python-playbook

A collection of Python CLI mini-programs based on the Udemy course *100 Days of Code: The Complete Python Pro Bootcamp* by Dr. Angela Yu. Built from scratch to practice core programming logic, control flow, and clean code, with all programs organized into a single interactive menu in `main.py`.

## Programs List
| No | Project | Core Concepts Practiced | Status |
| :--- | :--- | :--- | :--- |
| **01** | Band Name Generator | String manipulation, I/O, variables | ⏳ Pending |
| **02** | Tip Calculator | Data types, mathematical operations, f-strings | ⏳ Pending |
| **03** | Treasure Island | Conditional logic (`if/elif/else`), control flow | ⏳ Pending |
| **04** | Rock Paper Scissors | Randomization, Python lists, index logic | ⏳ Pending |
| **05** | Password Generator | `for` loops, `range()`, list shuffling | ⏳ Pending |
| **06** | Hangman | Lists, strings, state tracking, ASCII UI | ⏳ Pending |
